EDGE — Deterministic AI Governance Infrastructure

EDGE is a deterministic inference-time authorization layer that governs whether AI systems are allowed to act before generation occurs.

Vendor-neutral. Replayable. Fail-closed.

View Repository Run Local Demo

A New Layer in the AI Stack

Request → EDGE → {PROCEED | ASK_CLARIFY | REFUSE | ESCALATE} → Model / Tool Runtime
  • EDGE sits between intent and execution.
  • It authorizes actions before model output exists.
  • It is governance infrastructure, not a wrapper.

What EDGE Is

  • Deterministic governance kernel
  • Policy-versioned decision engine
  • Audit-grade artifact generator
  • Domain-agnostic enforcement layer

What EDGE Is Not

  • Not a chatbot
  • Not a prompt optimizer
  • Not a content filter
  • Not a model fine-tuning layer
  • Does not generate domain content
  • Does not execute tools

Supported Domains (Current v1.0)

  • Medicine (EDGE-Clinical)
  • Finance (decision-only)
  • Legal (decision-only, conservative)

Battle-Tested Determinism

  • Replayable Decisions — same input + same version → identical decision.
  • Version-Pinned Behavior — policy lifecycle is explicit and immutable.
  • Audit Artifacts — structured, machine-verifiable decision traces.

Why Now

  • LLMs are powerful enough to influence regulated decisions.
  • Prompt engineering is probabilistic.
  • Enterprises require enforceable authorization, not steering.
  • Governance must be infrastructure.
