# Licensing and Usage Notes

This document describes the intended usage model for EDGE. It is not a legal license or warranty. Formal licensing terms are provided under a separate agreement.

## Intended Usage Model
- **Evaluation**: limited, non-production testing to assess governance fit.
- **Pilot**: controlled deployment with restricted scope and explicit review.
- **Enterprise**: production deployment under negotiated terms.

## Non-Production Evaluation Allowance
Evaluation use is permitted for internal assessment and benchmarking. Production use should be governed by a formal agreement.

## Governance Infrastructure Statement
EDGE is governance infrastructure that returns deterministic decisions. It does not generate domain content or provide advice.
